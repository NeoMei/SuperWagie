常见问题

关于安装、模型 Key、资料库和数据位置的集中回答。

安装与系统

只有 macOS 吗？

统一发布提供 Apple 芯片 Mac 和 Windows x64 安装包。

为什么第一次打开被系统拦截？

安装包使用临时签名，没有做 Apple 公证。确认安装包可信且未被篡改后，请按首次打开说明先尝试启动，再到「隐私与安全性」中查看是否可选择「仍要打开」。

需要多少磁盘空间？

安装包大小以下载页标注为准。资料库索引和你的文件在原来的位置，索引数据库也在本机，具体大小取决于文件数量。

经验学习

打开资料库后，还需要单独打开经验学习吗？

不需要。开启资料库时服务端会启用经验学习；经验页的复选框仍可单独暂停或恢复。关闭资料库不会清除已保存的学习设置。

哪些对话会被自动提炼？

开关打开后，各项目中发生新对话的会话都会自动进入提炼范围，包括没有在当前窗口打开的会话。开关之前的会话，或当前打开的旧会话，可以手动选择「导入历史会话」。

从已开启资料库的旧版本升级会怎样？

升级后首次启动会补齐经验学习设置。打开经验页并刷新可查看状态。

提炼失败后还能重试吗？

可以。经验页会显示具体错误原因；临时失败的任务保留重试入口。模型额度、凭据或嵌入服务的问题需按提示处理后重试。

长中文内容会超过嵌入请求上限吗？

长中文内容按 UTF-8 字符边界分段，每次嵌入请求只提交一条短文本。

模型与 Key

要自己准备模型 Key 吗？

未配置模型时，应用会自动选择内置 OpenCode 中可用的免费模型。免费模型受服务方额度和可用性限制。需要更多模型能力时，点击头像，在用户面板订阅 SuperWagie Key；也可以在设置中添加自己的模型服务。明确选择的模型会保留。

Key 存在哪里？

本机使用的 Key 保存在 SuperWagie 的应用数据和内置 OpenCode 私有空间中，不随安装包分发。模型调用会使用 Key 向对应服务进行身份验证。系统 OpenCode 的凭据独立保存。

资料库还需要别的 Key 吗？

SuperWagie Key 可为资料库选择并配置可用的嵌入、图片理解和文档解析模型。各项能力是否可用，以模型测试与配置结果为准；也可以自行配置其他模型服务。

模型调用怎么计费？

SuperWagie Key 的调用会消耗账户余额或额度，可在用户面板查看钱包和消费记录。自行配置的供应商 Key 按对应供应商的规则计费。

资料库与隐私

资料库会把文件上传吗？

不会。文件留在原文件夹，犇马只在本机建立索引；解析和向量化会调用你配置的模型服务，发送的是需要的文本内容。

Agent 会改我的资料吗？

不会。资料库对 Agent 只读，它只能检索和读取，回答里带原文件路径。

删除文件会删掉索引吗？

磁盘上的文件被删除后，条目先标为缺失；确认后可以清理。删除索引本身不会删除原文件。

数据会在几台电脑之间同步吗？

不会自动同步。任务文件和资料库都在本机；要跨机器使用，需要自己同步文件或放进版本库。

任务与创作

任务存在哪里？

全局任务在 ~/.config/openchamber/tasks.md，项目任务在项目根目录的 任务.md，都是普通 Markdown，每行一条。

可以手改任务文件吗？

可以。工作台会检测外部修改并重新读取；行尾的 <!-- sw {...} --> 注释保存状态、截止时间和来源。

创作产出在哪里？

每个创作项目有自己的工作目录，通常在 ~/Documents/SuperWagie/ 下。最终文件和中间材料都在里面。

能改已经生成的文件吗？

能。打开原文件直接改，或者在会话里继续提要求；两者都作用于同一份文件。

编程与通用任务

能用来写代码吗？

可以。内置终端、代码检索和 Git 变更视图，Agent 能在项目里定位问题、改文件、跑命令和测试，改动可以逐条查看后再决定是否保留。

除了办公和写代码，还能做什么？

它是一个通用智能体：拆解目标、查找资料、调用工具、写文件，遇到长任务会自己分步骤做完再汇报。用在研究、整理资料、批量处理文件这些场景都可以。

支持与联系

有联系方式吗？

问题、缺陷和建议请发到问题反馈页面；安全问题按仓库里的说明私下报告。
