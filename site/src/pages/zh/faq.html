常见问题

关于安装、模型 Key、资料库和数据位置的集中回答。

安装与系统

只有 macOS 吗？

Apple 芯片 Mac 与 Windows x64 提供 2.7.43 安装包。下载页另有 Intel Mac 的 2.7.40-intel 兼容预发布及 Windows ARM64 的 2.7.34 兼容包，均按需发布并手动更新。macOS 12 与 Windows ARM 设备的安装和界面仍待实机验收。

为什么第一次打开被系统拦截？

安装包是 ad-hoc 签名、没有做 Apple 公证。右键应用图标选「打开」，确认一次之后就能正常双击启动。

需要多少磁盘空间？

安装包大小以下载页标注为准。资料库索引和你的文件在原来的位置，索引数据库也在本机，具体大小取决于文件数量。

模型与 Key

要自己准备模型 Key 吗？

是。犇马不附带 Key，也不要求使用某一家模型服务。在设置里添加供应商和 Key，选一个默认模型即可。

Key 存在哪里？

保存在这台电脑的本地配置和内核凭据里，不会随安装包分发，也不会上传到犇马的服务器。

资料库还需要别的 Key 吗？

可选。资料库的图片理解和 Wiki 合成使用 DeepSeek；不填也能索引和搜索文本，只是图片描述和部分合成能力不可用。

模型调用怎么计费？

按你选择的供应商计费。应用不代收模型费用。

资料库与隐私

资料库会把文件上传吗？

不会。文件留在原文件夹，犇马只在本机建立索引；解析和向量化会调用你配置的模型服务，发送的是需要的文本内容。

Agent 会改我的资料吗？

不会。资料库对 Agent 只读，它只能检索和读取，回答里带原文件路径。

删除文件会删掉索引吗？

磁盘上的文件被删除后，条目先标为缺失；确认后可以清理。删除索引本身不会删除原文件。

数据会在几台电脑之间同步吗？

不会自动同步。任务文件和资料库都在本机；要跨机器使用，需要自己同步文件或放进版本库。

任务与创作

任务存在哪里？

全局任务在 ~/.config/openchamber/tasks.md，项目任务在项目根目录的 任务.md，都是普通 Markdown，每行一条。

可以手改任务文件吗？

可以。工作台会检测外部修改并重新读取；行尾的 <!-- sw {...} --> 注释保存状态、截止时间和来源。

创作产出在哪里？

每个创作项目有自己的工作目录，通常在 ~/Documents/SuperWagie/ 下。最终文件和中间材料都在里面。

能改已经生成的文件吗？

能。打开原文件直接改，或者在会话里继续提要求；两者都作用于同一份文件。

编程与通用任务

能用来写代码吗？

可以。内置终端、代码检索和 Git 变更视图，Agent 能在项目里定位问题、改文件、跑命令和测试，改动可以逐条查看后再决定是否保留。

除了办公和写代码，还能做什么？

它是一个通用智能体：拆解目标、查找资料、调用工具、写文件，遇到长任务会自己分步骤做完再汇报。用在研究、整理资料、批量处理文件这些场景都可以。

支持与联系
