模型与 Key

SuperWagie 内置的 OpenCode 在独立空间中运行。未配置模型时，应用会自动选择其中可用的免费模型，保留用户明确选择的模型。免费模型受服务方额度和可用性限制。模型设置、凭据和运行数据与系统安装的 OpenCode 分开保存。

订阅 SuperWagie Key

  1. 点击头像打开用户面板，在「API 密钥」中开通 SuperWagie Key。
  2. 系统从当前 Key 的可用模型目录中，为对话、生图、嵌入、重排、图片识别、文档解析、语音合成等支持的用途选择适合的模型。仍可用且符合用途的已有模型会保留。
  3. 测试列表随着测试开始逐步展开，最多同时测试 3 项。每项分别显示连通测试和配置应用的结果，以及具体失败原因。
  4. 调用测试通过但已有知识索引阻止向量配置切换时，显示配置待处理，保留原配置和索引。完成兼容性确认及迁移前，不会自动重建索引。

目录中没有适合某项功能的模型时，该项会明确显示不可用原因。尚未配置价格的模型暂不可用。

继续配置已开通的 Key

如果页面显示密钥已开通，但模型配置失败，更新到 2.7.73 后选择「继续配置」。系统会沿用已保存的 Key，补齐内置 OpenCode 中缺失的凭据，再开始各项模型测试。已有的其他 Key 或模型配置发生冲突时，会保留原配置并提示原因。

测试通过，连接未完成

嵌入模型的调用测试通过，表示新连接可以返回向量。已有资料库索引还需要确认兼容性，才能应用这个连接；等待处理时，原配置和索引会保留。

同一模型、相同维度的连接切换，在完成兼容性校验和备份后可以迁移已有索引，无需重新导入资料。更换模型或维度时，需要评估迁移或重新生成索引。安装更新不会自动迁移或重建索引。

添加自己的模型服务

也可以进入「设置 → 模型服务」，添加供应商和 API Key，并选择默认模型。会话中可单独切换模型；新会话使用默认选择。

Key 和配置存在哪里

本机使用的 Key 保存在 SuperWagie 的应用数据和内置 OpenCode 私有空间中，不随安装包分发。模型请求会使用 Key 向对应服务进行身份验证。自动配置仅作用于内置实例；系统 OpenCode 使用自己的配置和凭据。

不要把 Key 贴进 issue、聊天记录或截图。需要分享日志时，先检查里面有没有凭据。

资料库模型

资料库使用 SuperWagie 中已配置的模型。SuperWagie Key 可统一配置可用的嵌入、图片理解和文档解析等能力；以各项测试与配置结果为准。也可以按需自行配置其他模型服务。

费用

点击头像可查看钱包、订阅、API 密钥、消费记录和个人资料。余额不足提示中的充值入口会直接打开用户面板的充值表单，提交前请确认金额。SuperWagie Key 的模型调用会消耗账户余额或额度。自行配置的供应商 Key 按对应供应商的规则计费。连通测试、资料解析和向量化也会调用模型。

常见报错

提示会跟随当前界面语言显示，展开详情可查看具体响应。

  • 模型尚未配置：未配置时可使用内置免费模型。需要使用其他模型时，点击头像开通 SuperWagie Key，或在设置中添加自己的模型服务。
  • 模型连接失败：检查连接设置和 Key 是否有效。已开通的 SuperWagie Key 可在用户面板继续配置。
  • 免费额度已用完：等待服务方恢复额度后重试，或选择已配置的其他模型。
  • 请求太频繁：稍等后重试。
  • 模型不可用：查看测试项中的原因，并检查当前 Key 的可用模型目录。
  • 内置 OpenCode 未就绪：等待引擎启动，刷新后继续配置；已开通的 Key 会保留。
