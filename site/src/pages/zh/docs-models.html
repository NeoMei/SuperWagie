模型与 Key

犇马在自己的应用数据目录中保存模型配置。未选定模型时，可使用当前可用的免费模型，额度和可用性由服务方决定。

测试通过，连接未完成

嵌入模型的调用测试通过，表示新连接可以返回向量。已有资料库索引还需要确认兼容性，才能应用这个连接；等待处理时，原配置和索引会保留。

同一模型、相同维度的连接切换，在完成兼容性校验和备份后可以迁移已有索引，无需重新导入资料。更换模型或维度时，需要评估迁移或重新生成索引。安装更新不会自动迁移或重建索引。

「自动」选模

在「设置 → 路由」中启用 Auto，并从当前可用模型中选择备用模型。模型被移除或所属服务变更后，需要在这里重新选择备用模型。

2.7.74 会在发送前检查模型选择。备用模型不可用时，会提示到路由设置中重新选择；某个类别的模型不可用时，使用已配置的备用模型，并保留该类别选中的智能体。相同名称的其他服务模型不会被自动替换使用。安装更新会保留已有路由设置。

添加自己的模型服务

也可以进入「设置 → 模型服务」，添加供应商和 API Key，并选择默认模型。会话中可单独切换模型；新会话使用默认选择。

Key 和配置存在哪里

犇马在应用数据中保存模型密钥，并使用它向所选模型服务进行身份验证。安装包不含用户密钥。

不要把 Key 贴进 issue、聊天记录或截图。需要分享日志时，先检查里面有没有凭据。

资料库模型

资料库和经验页使用「模型配置」中选定的模型。可按需为嵌入、文档解析等用途设置连接。

模型调用按所选供应商的规则计费。连通测试、文档解析和向量化也可能调用模型。

常见报错

提示会跟随当前界面语言显示，展开详情可查看具体响应。

  • 模型尚未配置： 可使用当前可用的免费模型，也可以在设置中添加自己的模型服务。
  • 模型连接失败： 检查设置中的端点、密钥和模型名称，并在可用时运行连接测试。
  • 免费额度已用完：等待服务方恢复额度后重试，或选择已配置的其他模型。
  • 请求太频繁：稍等后重试。
  • 模型不可用：查看测试项中的原因，并检查当前 Key 的可用模型目录。
  • 内置引擎 未就绪： 等待内置引擎启动后刷新页面。
