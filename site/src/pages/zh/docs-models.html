模型与 Key

犇马不绑定模型供应商。用哪一家、花多少钱，都由你决定。

添加供应商

  1. 打开「设置 → 模型服务」。
  2. 选择供应商，填入 API Key。OpenCode 支持的供应商都可以在这里接入。
  3. 选一个默认模型；会话里也可以单独切换。

Key 存在哪里

Key 保存在这台电脑的本地配置和 OpenCode 凭据里，不随安装包分发。安装包里没有 Key，也不会把 Key 上传到犇马的服务器。

不要把 Key 贴进 issue、聊天记录或截图。需要分享日志时，先检查里面有没有凭据。

资料库的可选 Key

资料库默认使用本机已有的模型配置。图片理解和 Wiki 合成可以另填一个 DeepSeek Key（设置 → 资料库）；不填也能索引和搜索文本，只是这两项能力不可用。

费用

模型调用由供应商计费。应用本身免费开源；资料库的解析和向量化也会调用模型，第一次索引前会提示文件数量和将使用的服务。

换模型

在会话顶部切换模型即可；新会话使用默认模型。已经生成的文件不会因为换模型而变化。

常见报错

  • 401 / 403：Key 无效、过期或没有该模型的权限。
  • 429：供应商限流或额度用尽。
  • 模型不可用：检查供应商状态，或在设置里换一个模型。
