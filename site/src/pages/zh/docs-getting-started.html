快速上手

从下载到写下第一件事，大约五分钟。首次启动需要登录 SuperWagie 账户。

1. 下载并安装

在下载页取最新的 DMG（Apple 芯片）。打开后把犇马拖进「应用程序」。安装包使用临时签名，没有做 Apple 公证。确认 2.7.71 修复包可信且未被篡改后，请按首次打开说明先尝试启动，再到「隐私与安全性」中查看是否可选择「仍要打开」。

2. 开始使用模型

登录后，新用户默认使用内置 OpenCode 的免费模型。需要更多模型能力时，在用户面板订阅 SuperWagie Key。系统会从这把 Key 的可用目录中选择适合各项功能的模型，测试通过后自动配置。

测试列表会随着测试开始逐步展开，最多同时测试 3 项。模型设置和 Key 只作用于 SuperWagie 的内置 OpenCode，系统安装的 OpenCode 使用自己的配置。

3. 写下第一件事

工作台是首页。在输入框里写「整理周五评审材料」，按回车；它会成为今天的一条任务。点任务可以开始一个会话，也可以直接勾掉。

4. 可选：添加资料库

需要让 Agent 读自己的合同和汇报时，打开右侧的资料库面板，添加一个目录。确认文件数量和将使用的模型后再开始索引；文件留在原处，不上传。

文件都在哪

  • 任务：全局 ~/.config/openchamber/tasks.md，项目 任务.md。
  • 资料库索引：~/.config/openchamber/embedded-knowledge/；原文件不动。
  • 创作产出：~/Documents/SuperWagie/ 下的工作目录。
  • 日志：~/Library/Logs/SuperWagie/main.log。

下一步：模型与 Key，或直接读工作台。
