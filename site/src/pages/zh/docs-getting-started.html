快速上手

从下载到开始第一项任务，大约五分钟。打开犇马即可进入工作区。

1. 下载并安装

在下载页取最新的 DMG（Apple 芯片）。打开后把犇马拖进「应用程序」。安装包使用临时签名，没有做 Apple 公证。确认安装包可信且未被篡改后，请按首次打开说明先尝试启动，再到「隐私与安全性」中查看是否可选择「仍要打开」。

2. 开始使用模型

可使用当前可用的免费模型，也可以在设置中添加自己的模型服务。

在「设置 → 模型服务」配置对话模型，在「模型配置」中设置语音转写或嵌入等用途的模型。

3. 写下第一件事

工作台是首页。在输入框里写「整理周五评审材料」，按回车；它会成为今天的一条任务。点任务可以开始一个会话，也可以直接勾掉。

4. 可选：添加资料库

需要让 Agent 读自己的合同和汇报时，打开右侧的资料库面板，添加一个目录。开启资料库时，服务端会启用「从新对话中学习」：之后各项目中发生新对话的会话都会自动进入经验提炼，包括没有在当前窗口打开的会话。经验页可单独暂停学习；开关之前的会话仍可手动导入。确认文件数量和将使用的模型后再开始索引；文件留在原处，不上传。

文件都在哪

  • 任务：全局 ~/.config/openchamber/tasks.md，项目 任务.md。
  • 资料库索引：~/.config/openchamber/embedded-knowledge/；原文件不动。
  • 创作产出：~/Documents/SuperWagie/ 下的工作目录。
  • 日志：~/Library/Logs/SuperWagie/main.log。
