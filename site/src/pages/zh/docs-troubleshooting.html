常见故障

先看日志：~/Library/Logs/SuperWagie/main.log。多数问题在最后几行有直接原因。

应用打不开

  • 如果 2.7.64 提示「已损坏」，请重新下载 2.7.75，并替换「应用程序」中的旧副本。新版本修复了应用包签名不完整的问题，仍未做 Apple 公证。
  • 确认下载的是可信且未被篡改的 2.7.75 修复包后，先尝试打开应用。如果因未公证而被拦截，进入「系统设置 → 隐私与安全性」，向下找到「仍要打开」，再按提示确认。参见 Apple 的打开说明。
  • 确认安装包与设备架构一致。Apple 芯片 Mac 的 arm64 安装包要求 macOS 13 或更高版本；Windows 提供 x64 安装包。
  • 如果没有「仍要打开」，或仍然无法启动，请在 Issues 中提供系统提示；如果已有应用日志，也可附上相关日志。

启动或会话报错

  • agent.list failed (403)：升级到 2.7.75。此版本修复桌面页面被新版内核来源检查拒绝的问题。
  • session.prompt failed (503)：内核启动或重启时，请求会等待它就绪；持续失败时检查日志中的具体原因。找不到会话会单独返回 404。
  • 找不到旧会话：SuperWagie 使用自己的私有会话库，不自动导入系统 OpenCode 的历史。可以在 SuperWagie 中新建会话，原库保持不变。
  • 密钥已开通，但配置失败：更新后，在用户面板的「API 密钥」中选择「继续配置」。已有 Key 会继续使用，无需再次开通。

模型报错

模型提示会跟随当前界面语言显示。展开响应详情，可查看排查所需的具体信息。

  • 自动模式提示模型不可用：进入「设置 → 路由」，从当前可用模型中重新选择备用模型。升级到 2.7.75 后，会在发送前提示失效的备用选择；更新会保留已有路由设置。
  • 模型尚未配置：未配置时可使用内置免费模型。需要使用其他模型时，点击头像开通 SuperWagie Key，或在设置中添加自己的模型服务。
  • 模型连接失败：检查连接设置和 Key 是否有效。已开通的 SuperWagie Key 可在用户面板继续配置。
  • 免费额度已用完：等待服务方恢复额度后重试，或选择已配置的其他模型。
  • 请求太频繁：稍等后重试。
  • 超时：检查网络，或换一个供应商。

嵌入测试通过，但连接未完成

已有索引触发了模型切换保护，原配置和索引会保留。无需先删除或重新导入资料。先确认是否能保留索引迁移；更换模型或维度时，再评估重建范围和费用。参见模型与 Key。

资料库索引失败

  • 加密的 Office 文件、损坏的压缩包、RTF 等格式无法解析；条目上会写原因。
  • 文件过大时会被跳过并标注，不会拖住整个库。
  • 修复文件后点重试；或先暂停这个库，整理完再继续。

资料库搜索不到

  • 确认索引已完成，而不是停在「索引中」。
  • 确认搜索范围是全部资料库还是当前库。
  • 文件名和语义是两组结果，换个关键词再试。

资料库服务没起来

退出应用再打开；服务会随应用启动，只监听本机。仍然失败时检查 17808 端口是否被占用，并把日志发出来。

任务文件被改坏

工作台会把无法解析的行列在任务列表下面，标出行号和原因。修正那一行，或从备份恢复；不会静默删除。

Windows

Windows x64 提供 2.7.75 安装包。安装包未签名，SmartScreen 可能拦截首次运行；安装包不包含任何 Key。
