常见故障

先看日志：~/Library/Logs/SuperWagie/main.log。多数问题在最后几行有直接原因。

应用打不开

  • 第一次打开被系统拦截：右键图标选「打开」，确认一次。
  • 确认安装包与设备架构一致。Apple 芯片选 arm64；Intel Mac 选 Intel 兼容版。Intel 兼容预发布为 2.7.39-intel，要求 macOS 12 Monterey 及以上，需手动更新。macOS 12 实机仍待验证。
  • 仍然打不开：在「系统设置 → 隐私与安全性」里允许，或把日志最后几行发到 Issues。

模型报错

  • 401 / 403：Key 无效或没有模型权限；在设置里重新保存。
  • 429：限流或额度用尽，换模型或稍后再试。
  • 超时：检查网络，或换一个供应商。

资料库索引失败

  • 加密的 Office 文件、损坏的压缩包、RTF 等格式无法解析；条目上会写原因。
  • 文件过大时会被跳过并标注，不会拖住整个库。
  • 修复文件后点重试；或先暂停这个库，整理完再继续。

资料库搜索不到

  • 确认索引已完成，而不是停在「索引中」。
  • 确认搜索范围是全部资料库还是当前库。
  • 文件名和语义是两组结果，换个关键词再试。

资料库服务没起来

退出应用再打开；服务会随应用启动，只监听本机。仍然失败时检查 17808 端口是否被占用，并把日志发出来。

任务文件被改坏

工作台会把无法解析的行列在任务列表下面，标出行号和原因。修正那一行，或从备份恢复；不会静默删除。

Windows

Windows x64 提供 2.7.39 安装包，Windows ARM64 兼容版为 2.7.34，需手动更新。ARM64 版含 x64 资料库服务和 x86 安装辅助程序，尚未完成 Windows ARM 实机验收。安装包未签名，SmartScreen 可能拦截首次运行；安装包不包含任何 Key。
