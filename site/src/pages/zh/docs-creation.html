创作

从一句话开始文档、PPT、视频或网页。每个创作有自己的工作目录，产出是真实文件。

开始

在工作台的输入框写下要求，选择「写文档 / 做 PPT / 做视频 / 做网页」，按回车。也可以直接在会话里说清楚要什么。

工作目录

创作的工作目录在 ~/Documents/SuperWagie/ 下，按项目命名。最终文件和中间材料都在里面，工作台、文件面板和访达都能直接打开。

四种产出

  • 文档：报告、方案、纪要；可编辑的 DOCX / PDF。
  • PPT：汇报、提案、课程；大纲、页面、图片和图表一起做。
  • 视频：演示片、讲解片；脚本、配音、画面和渲染。
  • 网页：落地页、产品页、单页；产出是可直接打开的 HTML 目录。

技能

SuperPPT、SuperWriter、SuperVideo、SuperWeb 随应用内置，不需要自己安装。它们决定每种产出的版式、渲染和文件格式。

用资料库里的材料

创作会话可以检索你索引过的合同和汇报，并把引用写进文档。资料库对 Agent 只读。

继续改

生成后可以直接打开文件改，也可以在会话里继续说「把第 4 页换成对比表」「语气收紧一点」。两种方式作用在同一份文件上。
