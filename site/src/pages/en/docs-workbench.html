Workbench

The workbench is home: what is due today, what got done this week and what you made recently, on one screen.

Tasks

Write what needs doing and press Enter. Open a task to start a session, or change its date, priority or state.

Task files

Tasks are plain Markdown, one per line:

- [ ] Turn the review pack into one page  <!-- sw {"state":"planned","due":"2026-10-23T14:00","priority":"high"} -->
- [x] Prepare three background pages    <!-- sw {"state":"completed","done":"2026-10-23"} -->
  • Global: ~/.config/openchamber/tasks.md
  • Project: 任务.md at the project root

Edit them in any editor. When the file changes elsewhere, the workbench rereads it instead of overwriting it.

Sticky notes

For things that are not tasks yet. Notes stay on this Mac, do not join project notes and are not written into the task file.

Calendar, counts and files

The right rail has a week and month calendar; pick a day to see only its tasks. Today, overdue, unscheduled and done-this-week are counts. Recent files lists documents, decks, videos and pages by modification time and opens the file itself.

Save a task from a chat

A conclusion in a session can become a task; the title and origin are written to the current project or the global task file.

After editing by hand

If a line cannot be parsed, the workbench lists it under “unparsed lines” with the line number and reason. Nothing is silently dropped.
