Create

Start a document, deck, video or web page from one sentence. Each creation has its own work folder, and the output is a real file.

Start

In the workbench composer, write the request and choose Document, Deck, Video or Web page, then press Enter. Or describe it in a session.

The work folder

Creation work folders live under ~/Documents/SuperWagie/, named after the project. Final and intermediate files are both there, openable from the workbench, the file panel or Finder.

Four outputs

  • Document: reports, proposals, minutes; editable DOCX / PDF.
  • Deck: reviews, pitches, lessons; outline, pages, images and charts together.
  • Video: demos and explainers; script, voice, scenes and rendering.
  • Web page: landing pages, product pages, one-pagers; an HTML folder you can open.

Skills

SuperPPT, SuperWriter, SuperVideo and SuperWeb ship with the app. They decide the layout, rendering and file format of each output.

Using the library

A creation session can search the contracts and reports you indexed and cite them in the document. The library stays read-only.

Keep editing

Open the generated file and edit it, or keep asking in the session: “swap page 4 for a comparison table”, “tighten the tone”. Both act on the same file.
