2.7.125 · Private credentials and inline forms

  • API keys, tokens and passwords can be entered through a private card. Values stay out of ordinary conversation content and command output is redacted.
  • Waiting forms appear beside the messages that requested them, with drafts, recovery and reading-history navigation preserved.
  • Desktop starts the bundled OpenCode 2.3.2 server by default while preserving the private workspace boundary.
  • OpenChamber Tools adds a persistent Agent Secret tool toggle.

2.7.121 · Product credits and membership

  • The account center shows your current membership, credit expiry dates, and credit packs. Unexpired packs are available again when you renew.
  • The shared wallet shows purchases and renewal settings for authorized products. You can use its cash balance for automatic membership renewal or credit-pack purchases at the threshold you choose.
  • An upgrade within the same billing interval starts a new term when payment is confirmed. The refundable value of the old plan goes back through its original payment method.
  • PaddleOCR PDF recognition in the built-in library charges 5 credits per successful request to the initiating user’s product wallet.

2.7.109 · Preview large Office files

  • Remove the fixed input-size ceiling for Office previews. Word, Excel and PowerPoint files no longer face the previous 30 MiB or 50 MiB input rejection.
  • The packaged Mac application read a 73.52 MiB, 63-slide PPTX in full through its file preview and generated all 63 slide previews.
  • Keep format and decompression checks, cancellation, timeouts and retry handling. Available device memory and format support still apply.
  • Known limitation: one WDP/JPEG XR image on slide 30 of that file does not decode in the browser. The other 340 image instances decoded successfully.

2.7.108 · Restore the chat flow and unify command folding

  • Restore OpenChamber 2.7.2 message text, independent reasoning, tool results, footers and status presentation.
  • Show consecutive commands in one bounded disclosure. Interleaved reasoning or prose keeps its source order. The command header retains its breathing indicator and shows no repeated command content while folded.
  • Keep results after completion so they can be expanded again. Automatic expansion follows the thinking preference; explicit reader choices take precedence. Direct ! commands use the same presentation.
  • Restore native structured UI messages, reference links, quote navigation and scrolling while preserving product themes and file previews.

Apple silicon Mac and Windows x64 installers include OpenCode 2.3.0. Open About in the app to check for updates, or visit the download page for installers and checksums.
