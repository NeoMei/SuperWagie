Frequently asked questions

Installation, model keys, the library and where your data lives.

Installation

Is it macOS only?

Apple silicon Mac and Windows x64 use 2.7.42. The download page also offers the 2.7.40-intel compatibility prerelease for Intel Mac and the 2.7.34 compatibility build for Windows ARM64. Both are released on request and require manual updates. Installation and the interface still need verification on macOS 12 and Windows ARM hardware.

Why does macOS block the first launch?

The app is ad-hoc signed and not notarised. Right-click the app, choose Open, and confirm once; after that it opens normally.

How much disk space does it need?

See the download page for current installer sizes. Your files stay where they are; the library index is local and grows with the number of files.

Models and keys

Do I need my own model key?

Yes. SuperWagie ships without keys and does not require one provider. Add a provider and key in Settings, then choose a default model.

Where is the key stored?

In local configuration and engine credentials on this Mac. It is never bundled with the installer or sent to SuperWagie’s servers.

Does the library need another key?

Optional. Image understanding and Wiki synthesis use DeepSeek; without that key, text indexing and search still work.

How are model calls billed?

By the provider you choose. The app does not bill for model usage.

Library and privacy

Does the library upload my files?

No. Files stay in their folders and the index is local. Parsing and embedding call the model provider you configured with the text they need.

Can the agent change my library?

No. The library is read-only to the agent: it can search and read, and answers cite the original path.

Does deleting a file remove the index?

A file removed from disk is first marked missing; clean up the entry when you are sure. Removing the index never deletes the original.

Does it sync between Macs?

Not automatically. Task files and the library are local; sync the files yourself or keep them in a repository.

Tasks and creation

Where do tasks live?

Global tasks in ~/.config/openchamber/tasks.md; project tasks in 任务.md at the project root. Both are plain Markdown, one line per task.

Can I edit the task file by hand?

Yes. The workbench rereads external changes; the trailing <!-- sw {...} --> comment holds state, due date and origin.

Where does creation output go?

Each creation has a work folder under ~/Documents/SuperWagie/ with final and intermediate files.

Can I edit a generated file?

Yes. Open the original and edit it, or keep asking in the session; both act on the same file.

Coding and general tasks

Can I use it to write code?

Yes. A built-in terminal, code search and a Git diff view let the agent find the problem in a project, change files, run commands and tests, and you can review each change before keeping it.

What else is it for?

It is a general-purpose agent: it breaks a goal into steps, looks things up, calls tools and writes files, then reports back. Research, tidying material and batch file work all fit.
