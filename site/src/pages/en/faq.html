Frequently asked questions

Installation, model keys, the library and where your data lives.

Installation

Is it macOS only?

The unified release provides Apple silicon Mac and Windows x64 installers.

Why does macOS block the first launch?

The app is ad-hoc signed and not notarised. For a trusted, unmodified package, follow the first-launch instructions to try opening it, then use Open Anyway in Privacy & Security if available.

How much disk space does it need?

Leave free disk space for the downloaded installer and the installed app. Your files stay where they are; the library index is local and grows with the number of files.

Experience learning

Does the library need a separate learning switch?

No. The server enables experience learning when you turn the library on. The Experiences checkbox remains available to pause or resume it. Turning the library off keeps the saved learning setting.

Which conversations are captured automatically?

Once learning is enabled, every session with a later conversation in any project enters extraction automatically, including sessions you do not have open. Sessions from before enablement, or an older open session, can be imported explicitly.

What happens after upgrading with the library already on?

The first launch after upgrading applies the shared learning setting. Refresh the Experiences tab to check its state.

Can a failed extraction be retried?

Yes. The Experiences tab shows a specific error, and transient failures keep retry available. Resolve model quota, credential or embedding service problems before retrying.

Does long Chinese content exceed the embedding request limit?

Long content is split at UTF-8 character boundaries, and each embedding request carries one short text.

Models and keys

Do I need my own model key?

When no model is configured, the app selects an available free model from the bundled OpenCode. Free models remain subject to provider limits and availability. For more model capabilities, click your avatar to subscribe to a SuperWagie Key in the account panel, or add your own provider in Settings. Explicit model choices are preserved.

Where is the key stored?

Keys used locally are stored in SuperWagie's application data and its bundled OpenCode's private space. Model requests use the key to authenticate with the selected service. Installers contain no user keys, and system OpenCode credentials are stored separately.

Does the library need another key?

A SuperWagie Key can select and configure available embedding, image understanding and document parsing models for the library. Each capability depends on its model test and setup result. You can also configure another provider.

How are model calls billed?

SuperWagie Key calls consume account balance or quota, shown in the account panel's wallet and usage records. A separately configured provider key follows that provider's billing rules.

Library and privacy

Does the library upload my files?

No. Files stay in their folders and the index is local. Parsing and embedding call the model provider you configured with the text they need.

Can the agent change my library?

No. The library is read-only to the agent: it can search and read, and answers cite the original path.

Does deleting a file remove the index?

A file removed from disk is first marked missing; clean up the entry when you are sure. Removing the index never deletes the original.

Does it sync between Macs?

Not automatically. Task files and the library are local; sync the files yourself or keep them in a repository.

Tasks and creation

Where do tasks live?

Global tasks in ~/.config/openchamber/tasks.md; project tasks in 任务.md at the project root. Both are plain Markdown, one line per task.

Can I edit the task file by hand?

Yes. The workbench rereads external changes; the trailing <!-- sw {...} --> comment holds state, due date and origin.

Where does creation output go?

Each creation has a work folder under ~/Documents/SuperWagie/ with final and intermediate files.

Can I edit a generated file?

Yes. Open the original and edit it, or keep asking in the session; both act on the same file.

Coding and general tasks

Can I use it to write code?

Yes. A built-in terminal, code search and a Git diff view let the agent find the problem in a project, change files, run commands and tests, and you can review each change before keeping it.

What else is it for?

It is a general-purpose agent: it breaks a goal into steps, looks things up, calls tools and writes files, then reports back. Research, tidying material and batch file work all fit.

How do I get in touch?

Use the feedback page for bugs and suggestions; report security issues privately as described in the repository.
