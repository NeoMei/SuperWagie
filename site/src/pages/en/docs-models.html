Models & keys

SuperWagie's bundled OpenCode runs in a private space. When no model is configured, the app selects an available free model and preserves explicit model choices. Free models remain subject to provider limits and availability. Model settings, credentials and runtime data are stored separately from a system OpenCode installation.

Subscribe to a SuperWagie Key

  1. Click your avatar to open the account panel and activate a SuperWagie Key under API keys.
  2. Setup selects suitable models from the key's current catalog for supported purposes such as chat, image generation, embedding, reranking, image understanding, document parsing and speech synthesis. An existing model stays selected when it is still available and supports its purpose.
  3. The list grows as tests start, with up to 3 running together. Each row shows separate connectivity and configuration results, with a specific reason when either step fails.
  4. If model calls pass but an existing knowledge index prevents applying the embedding configuration, setup remains pending and the original configuration and index are preserved. Indexes are not automatically rebuilt before compatibility and migration are confirmed.

A feature without a compatible model shows why it is unavailable. Models without configured prices are unavailable.

Continue setup with an activated key

If the key is activated but model configuration failed, update to 2.7.73 and choose Continue setup. Setup reuses the saved key, restores its missing credential in the bundled OpenCode, then starts model tests. A conflicting key or model configuration is retained with an explanation.

Test passed, connection incomplete

A passed embedding test means the new connection can return vectors. Applying it to an existing library index also requires a compatibility check. The original configuration and index remain while that check is pending.

A connection change with the same model and dimensions can preserve existing vectors through a controlled migration after compatibility checks and a backup. Files do not need to be imported again for that migration. Changing the model or dimensions requires assessing migration or regenerating the index. Installing an update does not migrate or rebuild an index automatically.

Add your own provider

You can also open Settings → Model providers, add a provider and API key, and choose a default model. A session can switch models individually; new sessions use the default selection.

Where keys and settings live

Keys used locally are stored in SuperWagie's application data and its bundled OpenCode's private space. Model requests use the key to authenticate with the selected service. Installers contain no user keys. Automatic setup applies only to the bundled instance; system OpenCode keeps its own settings and credentials.

Never paste a key into an issue, a chat or a screenshot. Check logs for credentials before sharing them.

Library models

The library uses models configured in SuperWagie. A SuperWagie Key can configure available embedding, image understanding and document parsing capabilities. Each capability depends on its test and setup result. You can also configure another provider when needed.

Cost

Click your avatar to view your wallet, subscription, API keys, usage and profile. A low-balance notice opens the account panel's funding form; confirm the amount before submitting. SuperWagie Key calls consume account balance or quota. A separately configured provider key follows that provider's billing rules. Connectivity tests, document parsing and embedding also call models.

Common errors

Messages follow the current interface language. Expand the details to inspect the response.

  • Model not set up: use a bundled free model when no model is configured. To use another model, click your avatar to activate a SuperWagie Key, or add your own provider in Settings.
  • Model connection failed: check the connection settings and key. If your SuperWagie Key is already activated, continue setup in the account panel.
  • Free allowance used up: wait for the service to restore the allowance, or choose another configured model.
  • Too many requests: wait a little, then try again.
  • Model unavailable: read the test result and check the key's current model catalog.
  • Bundled OpenCode is not ready: wait for the engine to start, then refresh and continue setup. The activated key is retained.
