Models & keys

SuperWagie's bundled OpenCode runs in a private space. New users start with its available free models. Model settings, credentials and runtime data are stored separately from a system OpenCode installation.

Subscribe to a SuperWagie Key

  1. Open the account panel and activate a SuperWagie Key under API keys.
  2. Setup selects suitable models from the key's current catalog for supported purposes such as chat, image generation, embedding, reranking, image understanding and document parsing. An existing model stays selected when it is still available and supports its purpose.
  3. The list grows as tests start, with up to 3 running together. Each row shows testing, success or a specific failure reason. Successful connections are applied to the corresponding features.

A feature without a compatible model shows why it is unavailable. Models without configured prices are unavailable. Changing the embedding model may require rebuilding an existing library index; follow the app's instructions.

Continue setup with an activated key

If the key is activated but model configuration failed, update to 2.7.70 and choose Continue setup. Setup reuses the saved key, restores its missing credential in the bundled OpenCode, then starts model tests. A conflicting key or model configuration is retained with an explanation.

Add your own provider

You can also open Settings → Model providers, add a provider and API key, and choose a default model. A session can switch models individually; new sessions use the default selection.

Where keys and settings live

Keys used locally are stored in SuperWagie's application data and its bundled OpenCode's private space. Model requests use the key to authenticate with the selected service. Installers contain no user keys. Automatic setup applies only to the bundled instance; system OpenCode keeps its own settings and credentials.

Never paste a key into an issue, a chat or a screenshot. Check logs for credentials before sharing them.

Library models

The library uses models configured in SuperWagie. A SuperWagie Key can configure available embedding, image understanding and document parsing capabilities. Each capability depends on its test and setup result. You can also configure another provider when needed.

Cost

SuperWagie Key calls consume account balance or quota. The account panel provides a wallet and usage records. A separately configured provider key follows that provider's billing rules. Connectivity tests, document parsing and embedding also call models.

Common errors

  • 401 / 403: the key is invalid, expired or lacks access to that model.
  • 429: rate limit or quota exhausted.
  • Model unavailable: read the test result and check the key's current model catalog.
  • Bundled OpenCode is not ready: wait for the engine to start, then refresh and continue setup. The activated key is retained.
