Models & keys

SuperWagie does not lock you to a provider. Which model you use, and what it costs, is your call.

Add a provider

  1. Open Settings → Model providers.
  2. Choose a provider and paste the API key. Any provider OpenCode supports can be added here.
  3. Pick a default model; a session can switch models on its own.

Where the key lives

In local settings and OpenCode credentials on this Mac. It is never bundled with the installer and never sent to SuperWagie’s servers.

Never paste a key into an issue, a chat or a screenshot. Check logs for credentials before sharing them.

The library’s optional key

The library uses the model configuration already on the machine. Image understanding and Wiki synthesis can use a separate DeepSeek key (Settings → Library). Without it, text indexing and search still work.

Cost

Model calls are billed by the provider. The app is free and open source; parsing and embedding in the library also call a model, and the first index shows the file count and the service it will use.

Switching models

Switch from the top of a session; new sessions use the default. Files already generated do not change when the model does.

Common errors

  • 401 / 403: the key is invalid, expired or lacks access to that model.
  • 429: rate limit or quota exhausted.
  • Model unavailable: check the provider status or choose another model in Settings.
