The workbench is home. Write tomorrow’s first task, or start a session straight away. When you need your own material, add a library folder from the right rail.

  • Models. Settings → Model providers; add a provider key and pick a default model.
  • Library (optional). Settings → Library; add the optional DeepSeek key for image understanding and Wiki synthesis.
  • Tasks. Global tasks in ~/.config/openchamber/tasks.md; project tasks in 任务.md.

Requirements

  • macOS (Apple silicon) and Windows x64 / ARM64 builds are available; there is no official Intel Mac build.
  • A network connection for model calls; tasks, the library index and keys stay local.
  • The library starts a bundled indexing service on loopback. Nothing else to install.

Windows and Intel

EXE installers are available for Windows x64 and ARM64. The ARM64 version requires Windows 11. There is no official Intel Mac build; build from source if needed. The installer ships with no keys.

Verifying the download

Each button downloads the installer directly. This page provides a macOS DMG and Windows x64 / ARM64 EXE installers; the installer contains no model keys, accounts or library content.
