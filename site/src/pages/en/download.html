Requirements

  • macOS (Apple silicon) and Windows x64 builds are available; there is no official Intel Mac build.
  • A network connection for model calls; tasks, the library index and keys stay local.
  • The library starts a bundled indexing service on loopback. Nothing else to install.

Windows and Intel

The Windows x64 installer has passed install validation and is unsigned. There is no official Intel Mac build; build from source if needed. The installer ships with no keys.
