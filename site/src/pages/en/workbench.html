Tasks are your own files

Tasks are not locked in a database. Global tasks live in ~/.config/openchamber/tasks.md; project tasks live in 任务.md at the project root. One line per task, with a trailing comment for state, due date and origin.

  • Edit them anywhere. Open them in any editor, commit them, sync them to another Mac — they are still the same tasks.
  • External edits survive. When the file changes elsewhere, the workbench rereads it instead of overwriting it with stale state.
  • Save from a chat. A conclusion in a session can become a task on today’s list.

More than today, kept in place

The right rail holds the calendar, today / overdue / unscheduled / done this week, and the sessions and files you touched last. Click a day to see only that day’s tasks.

  • Sticky notes. For things that are not tasks yet. Stored locally, never mixed into the task list.
  • Recent files. Documents, decks, videos and pages, ordered by modification time. Open the file itself.
  • No second to-do system. A task with a time is a plan; one without is a to-do. Both live in the same file.
