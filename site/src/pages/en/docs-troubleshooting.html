Troubleshooting

Start with the log: ~/Library/Logs/SuperWagie/main.log. The last few lines usually name the cause.

The app will not open

  • If macOS blocks the first launch, right-click the icon and choose Open, then confirm.
  • Match the installer to your Mac. Choose arm64 for Apple silicon or the Intel compatibility build for an Intel Mac. The 2.7.40-intel local compatibility prerelease requires macOS 12 Monterey or later and manual updates. OpenCode runs locally, with project files, knowledge and memory stored on this Mac. macOS 12 hardware acceptance remains unverified.
  • The earlier 2.7.39-intel release is a remote client. Download and install 2.7.40-intel for local execution on this Mac.
  • Still stuck: allow it in System Settings → Privacy & Security, or attach the last log lines to an issue.

Model errors

  • 401 / 403: invalid key or no access to the model; save it again in Settings.
  • 429: rate limit or quota; switch models or try later.
  • Timeouts: check the network or try another provider.

Indexing fails

  • Encrypted Office files, broken archives and formats such as RTF cannot be parsed; the entry says why.
  • Files over the size limit are skipped and labelled, so one large file cannot stall the library.
  • Fix the file and retry, or pause the library while you tidy it.

Search returns nothing

  • Check that indexing finished, rather than sitting at “indexing”.
  • Check the scope: all libraries or the current one.
  • Filename and meaning are separate result groups; try another term.

The library service is down

Quit and reopen the app; the service starts with it and listens only on loopback. If it still fails, check whether port 17808 is taken and share the log.

A task file got broken

The workbench lists unparsed lines below the tasks with the line number and reason. Fix the line or restore a backup; nothing is silently deleted.

Windows

Windows x64 uses 2.7.40. The Windows ARM64 compatibility build uses 2.7.34 and requires manual updates. It includes an x64 library service and an x86 installation helper, and has not been verified on Windows ARM hardware. The installers are unsigned, so SmartScreen may block the first run. They contain no keys.
