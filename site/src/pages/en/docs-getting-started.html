Getting started

From download to the first task, about five minutes. Open SuperWagie to enter your workspace.

1. Download and install

Get the latest DMG from the download page (Apple silicon). Open it and drag SuperWagie into Applications. The build is ad-hoc signed and not notarised. For a trusted, unmodified package, follow the first-launch instructions to try opening it, then use Open Anyway in Privacy & Security if available.

2. Start using models

Use an available free model or add your own provider in Settings.

In Settings, use Providers for chat models and Model configuration for tasks such as transcription or embedding.

3. Write the first task

The workbench is home. Type “tidy Friday’s review pack” and press Enter; it becomes today’s task. Open it to start a session, or tick it off.

4. Optional: add a library

To let the agent read your own contracts and reports, open the library panel on the right and add a folder. Turning on the library makes the server enable learning from new conversations. Every session with a later conversation in any project enters experience extraction automatically, including sessions you do not have open. The Experiences tab can pause learning; older sessions remain available for explicit import. Confirm the file count and the model before indexing; files stay where they are and are never uploaded.

Where things live

  • Tasks: global ~/.config/openchamber/tasks.md, project 任务.md.
  • Library index: ~/.config/openchamber/embedded-knowledge/; originals untouched.
  • Creation output: work folders under ~/Documents/SuperWagie/.
  • Logs: ~/Library/Logs/SuperWagie/main.log.
