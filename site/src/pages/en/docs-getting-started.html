Getting started

From download to the first task, about five minutes. Sign in to your SuperWagie account on first launch.

1. Download and install

Get the latest DMG from the download page (Apple silicon). Open it and drag SuperWagie into Applications. The build is ad-hoc signed and not notarised. For a trusted, unmodified 2.7.72 repair package, follow the first-launch instructions to try opening it, then use Open Anyway in Privacy & Security if available.

2. Start using models

After signing in, the app selects an available OpenCode free model when no model is configured. Explicit model choices are preserved. Free models remain subject to provider limits and availability; try again later if the free allowance is used up. For more model capabilities, click your avatar and subscribe to a SuperWagie Key in the account panel. Setup selects models for each supported feature from the key's available catalog and configures them after successful tests.

The list grows as tests start, with up to 3 running together. Model settings and keys apply to SuperWagie's bundled OpenCode. A system OpenCode installation keeps its own configuration.

3. Write the first task

The workbench is home. Type “tidy Friday’s review pack” and press Enter; it becomes today’s task. Open it to start a session, or tick it off.

4. Optional: add a library

To let the agent read your own contracts and reports, open the library panel on the right and add a folder. Confirm the file count and the model before indexing; files stay where they are and are never uploaded.

Where things live

  • Tasks: global ~/.config/openchamber/tasks.md, project 任务.md.
  • Library index: ~/.config/openchamber/embedded-knowledge/; originals untouched.
  • Creation output: work folders under ~/Documents/SuperWagie/.
  • Logs: ~/Library/Logs/SuperWagie/main.log.
