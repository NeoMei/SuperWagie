Your folder is the library

Add a directory and SuperWagie reads the contracts, reports and references where they live. Search names and meaning together; open the original.

  • Indexed in place. Files are not moved or uploaded; removing the index never touches the originals.
  • One search box. Name matches first, then relevant passages, with the reason it matched.
  • Read-only agent. Answers carry the file path; it never edits your material.

The Wiki and relationship graph are generated from those documents; every node leads back to the source.
