Library

Turn a local folder into a library you can search and cite. Nothing moves; nothing is uploaded.

Add a folder

  1. Open the library panel on the right and choose Add folder.
  2. Confirm the file count, supported formats and the model that will be used.
  3. Start indexing; you can keep working.

The index points at each file where it lives. Nothing is copied, and deleting the index never deletes the originals.

What it indexes

  • PDF, JPG, PNG and TIFF go through OCR / image understanding.
  • Word, PowerPoint, Excel and other Office files go through document parsing.
  • Broken archives, encrypted documents and unsupported formats show a reason and can be retried.

Search

One box returns both kinds of result: filename matches first, then relevant passages, with file, path and page. Open a result to see the original; text formats jump to the passage.

Wiki, graph and gallery

Indexed documents produce Wiki pages and a relationship graph; the gallery browses images and layouts. Every node leads back to its source.

How the agent uses it

When a session needs a fact, the agent searches the library and cites paths. The library is read-only to the agent; it cannot edit or delete your files.

Removing and pausing

  • A file missing from disk is marked missing first; remove the entry when you are sure.
  • Pause stops indexing without removing the library.
  • Remove stops and drops the index; you can choose whether to delete index data. Originals never move.

The indexing service

It starts with the app and listens only on loopback; there is nothing to install. Logs live in ~/Library/Logs/SuperWagie/main.log.
