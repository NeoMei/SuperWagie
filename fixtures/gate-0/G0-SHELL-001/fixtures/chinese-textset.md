## 中英混排长段落

SuperWagie 超级牛马是一个运行在 macOS 与 Windows 11 上的知识工作 Agent 客户端。它把 Workspace、Markdown、任务、交付物（PPT / Word / HTML / 视频）和 Agent 会话整合在同一个封闭 Runtime 中，通过官方 Model Gateway 统一计费。The user opens the client, signs in once, and starts working; credits are consumed transparently, and every capability — from draw.io diagrams to WPS review — degrades independently when a dependency is missing. 依赖缺失只影响对应能力，不影响 Workspace 与其他功能的启动（R-RI-08 能力级降级）。
