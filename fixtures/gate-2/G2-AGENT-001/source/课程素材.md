# AI Agent 课程素材

大模型负责理解和生成，Harness 负责把模型放进一个可以工作的环境，Tools 负责读取文件、调用服务和产生结果。Agent 不是单次回答，而是在目标、上下文、工具、状态和反馈之间循环。

面向非技术用户时，应避免把模型参数、调用链和内部错误原样暴露。更好的解释方式是：先确认目标和材料，再制定步骤；每一步产生可见中间结果；遇到缺口时说明缺什么；高风险或高成本动作在执行前确认；失败后从检查点恢复。

教学演示需要同时覆盖成功路径和边界：资料不足时不能直接生成看似完整的内容；引用必须能回到来源；用户修改上游材料后，只重做受影响部分；停止任务不等于删除任务；Credits 不等于 Token。
