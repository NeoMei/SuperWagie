# 技术约束摘要

SuperWagie 的 Agent 核心运行在封闭环境中，不发现、不连接机器已有 Codex Server，也不读取全局 Skills、MCP、配置或缓存。Python、Node、Git、FFmpeg、WPS 和系统库可以作为公共 Runtime 复用，但必须经过绝对路径、版本、架构、身份与 feature probe 验证；依赖缺失只降级相关能力。

官方 Skill 与用户 Skill 通过同一 Public Capability Facade 和 Managed AI Runtime 使用模型能力。Provider、模型名、Base URL 与 Key 对用户不可见，凭据只由服务端 Broker 管理。文件写入必须受 Workspace Root、revision、事务与 Artifact ownership 约束。高权限 Host、用户扩展和普通 WebView 在进程、协议与权限上分离。

工作流以稳定 stage ID、Human Gate、checkpoint、幂等 request ID 和 effect receipt 组织。外部动作结果未知时进入 reconcile，不能盲目重放。第二阶段优先把安全、事务、路由、索引和 Durable Workflow 核心迁移到 Rust，但不为语言迁移牺牲格式质量。
