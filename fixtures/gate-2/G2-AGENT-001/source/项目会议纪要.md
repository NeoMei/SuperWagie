# 项目会议纪要

## 已确认

1. 默认入口是智能工作区，内容整理完成后再选择 PPT、Word、HTML 或视频交付。
2. 工作台包含时钟、日历、待办、项目和统计，但不承担扩展安装。
3. 任务只做到项目 Milestone 粒度，可由用户、Agent 对话或项目进展创建。
4. PPT 默认使用高保真图片页，指定页面才做可编辑重建；风格阶段必须展示真实样页。
5. HTML 只发布到官方 Host，一键生成稳定分享链接，支持更新、回滚和停止分享。
6. 视频使用自有轻量运行时，首发五个 Profile；不直接打包 OpenMontage 或 Remotion。

## 未决事项

- Windows 真实宿主验证尚未完成；
- WPS 商业使用与分发条款需要有权角色确认；
- 官方 Gateway、支付渠道沙箱和 Official Host 测试环境尚未提供；
- SuperPPT 正在开发，尚未冻结 Capability Candidate。
