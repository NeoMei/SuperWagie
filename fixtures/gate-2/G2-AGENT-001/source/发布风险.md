# 发布风险登记

| 风险 | 概率 | 影响 | 当前措施 |
|---|---:|---:|---|
| Windows WebView 行为差异 | 中 | 高 | 相同 fixture 在 Windows 11 复跑 |
| WPS 渲染或授权变化 | 中 | 高 | 锁定版本与来源，保留外部 WPS fallback |
| 用户扩展越权 | 中 | 高 | 默认断网、无任意 shell、Broker 审计 |
| 长任务重复扣费 | 低 | 高 | Reservation、幂等 request ID、effect receipt |
| 视频依赖包过大 | 高 | 中 | 按能力下载 Headless Chromium，FFmpeg feature probe |
| 项目文档被同步覆盖 | 低 | 高 | revision、事务、冲突与人工确认 |
| 第三方许可证不清 | 中 | 高 | SBOM、NOTICE、有权角色签署，未通过不发布 |

风险降低不等于风险消失。缺少 Windows、干净机器、支付沙箱或法律签署时，应标记为环境阻塞或条件通过，不允许用“本机看起来能跑”替代。
