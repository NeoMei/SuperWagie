# 竞品观察

传统聊天产品擅长快速问答，但项目文件、阶段与任务通常分散。在线文档产品协作成熟，却常把 AI 放在侧边栏，无法可靠管理长任务副作用。专业 PPT 和视频工具格式能力强，但要求用户理解模板、时间线或复杂参数。

SuperWagie 的差异点应是统一内容工作区、真实本地文件、Agent 引导制作和可恢复工作流，而不是堆叠更多模型入口。产品应把复杂度放在系统内部：对外只有项目、任务、内容、交付物、Review 和 Credits；对内才处理模型路由、依赖、沙箱、事务、版本和计量。

主要风险是功能很多但闭环不完整。如果 Markdown 很像 Obsidian，但 Office 预览失真，用户仍会离开应用；如果视频能生成，却不能局部返工和追踪素材来源，也难以用于正式工作。
