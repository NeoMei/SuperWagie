# 产品访谈摘录

访谈对象包括高校教师、企业方案经理、项目负责人和内容运营。共同问题不是“缺一个聊天框”，而是材料散落、任务没有上下文、生成结果难以继续修改。教师希望从课程资料整理到课件、讲解视频都在同一项目中完成；方案经理希望长文档、PPT 和来源之间可追溯；项目负责人希望 Agent 的工作能形成明确任务、阶段和可恢复记录。

多数受访者不理解模型、Provider、Token 或 API Key，也不希望管理这些设置。他们愿意看到统一 Credits、预计增量和本次会话累计消耗。对高成本操作，他们接受在正常对话中确认一次，但反感每轮都弹窗。

文档体验方面，用户希望 Markdown 像 Obsidian 一样可直接编辑、阅读、链接和嵌入；Office 文件则更在意版式不走样和可批注，不要求应用重做一套文字排版器。跨设备场景重点是项目记忆与团队共享知识，不是把未完成的本机副作用自动搬到另一台机器继续执行。
