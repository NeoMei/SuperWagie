# SuperWeb design source note

SuperWeb previously consulted
[`elayadesign/ai-design-skills`](https://github.com/elayadesign/ai-design-skills)
and its `landing-page-design` skill for content realism, visual tokens, motion,
and interaction coverage.

Those ideas are now merged into SuperWeb's own contract. Runtime behavior has
one source of truth:

- Agent rules: [`SKILL.md`](../SKILL.md)
- Generated contract: [`src/guided.ts`](../src/guided.ts)
- Route blueprints and direction data: [`src/directions.ts`](../src/directions.ts)

Do not load this note as a second skill and do not copy rules from the external
repository into a task. Use `设计引导.md` generated by SuperWeb and follow the
current `SKILL.md`. The external repository is MIT licensed; this note records
provenance only.
