## 7. 已废弃方向

- Neumorphism、Claymorphism 和由其衍生的工作台变体全部废弃；统一回到暖调、清晰、克制的编辑式界面。
- `workbench-restored-i2.html`、`workbench-compact-start-v3.html` 和 `workbench-start-card-v4.html` 都不是最终首页基线；首页只以 `confirmed-i2-original-replay.html` 及其在 `four-view-overall-confirmation.html` 中的同版缩略图为准。
- `video-budget-confirmation-a.html` 的大块 Credits 卡片已经废弃，由 `agent-session-credits-fixed-a.html` 取代。
- 大通栏“今天想完成什么”输入框及大标题与输入框并排的方案已经废弃。

## 8. 覆盖审计结论

已确认原型覆盖：首次进入、主工作台、项目与任务、Tasks 四个实施界面、智能工作区、Markdown、绘图、交付入口、内容就绪、PPT、Word、HTML、视频、Office Review、Agent 状态、通知、权限、Credits、设置和用户扩展。

界面层没有阻止编写 Technical Validation Plan 的结构性缺口。生产组件的 View ID、职责、布局、焦点、快捷键、状态、数据源和验收见 [SuperWagie UI 实施契约](superpowers/specs/2026-08-29-superwagie-ui-implementation-contract.md)。后续原型只应服务于实现中发现的具体问题，不再以增加页面数量作为设计进度。
