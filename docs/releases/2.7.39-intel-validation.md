# SuperWagie 2.7.39-intel validation

Executable source is `0d615409f4a733c9ea7d2c3e647b95038a76a32f`. This optional release targets Intel Macs on macOS 12 Monterey or later and pins Electron 43.8.4, Node 24.22.1 and ABI 148. Its packaged mode is `remote-client`.

## Behavior

The client connects to a separate SuperWagie service that hosts OpenCode. Project files, knowledge and memory belong to that remote service. A bare OpenCode endpoint is not a SuperWagie instance endpoint. The local backend, OpenCode binary, knowledge backend, memory runtime, SuperWeb and native speech/PTY modules are omitted. Inherited shell settings cannot enable the local backend. Existing local journals and stale writer records remain untouched.

First launch exposes Switch instance, Add instance and the existing Add server editor before login. The recovery editor requires no runtime provider and performs no authenticated device-management reads. Account authentication remains required. The normal authenticated Settings path and ordinary desktop distribution remain unchanged. Intel app updates require manual downloads, and the ARM64 update feed is never offered.
